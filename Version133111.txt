We've created a new beta branch called "crashfix" for those who have had issues with crashes on startup. This branch uses an updated version of Unity, but is otherwise the same as the current stable branch.

Right click RimWorld -> Properties -> Betas -> select "crashfix". You may need to restart Steam to have it appear.

Let us know if this fixes the crashes! Also, let us know if this branch breaks mods.
