'''Ancient transport pods''' are a single-use form of transportation found in orbital wrecks and asteroids.

== Acquisition ==
{{Stub|section=1|reason=Acquisition stub - verify spawn chances for all map types and report here}}
Ancient transport pods cannot be crafted and can only be generated as a part of a map.

== Summary ==
{{Stub|section=1|reason=Summary stub. See [[transport pod]] and [[pod launcher]] for sufficient detail}}
Ancient transport pods are still functional and work similarly to player-built [[transport pod]]s, but with a range of 53 tiles, which is 80% of the player-built pods.

== Analysis ==
Ancient transport pods are a way to send colonists from orbital maps back to the main base if the transport method they used to arrive is not usable for the return trip. It can also be used to send items to the main base that exceed the weight limit of a shuttle, avoiding multiple trips back-and-forth from base to orbit. Orbital wrecks and asteroids are guaranteed to have an ancient transport pod, so pawns will be able to get back in an emergency. Additionally, ancient launch sites have a chance to generate with ancient transport pods. {{Check Tag|Chance?|The XML files say 0.3 but I don't know how that works exactly.}}
