The '''ship computer core''' is a [[ship]] part that provides the ship's navigation and control center. Building it requires a [[persona core]], which can only be acquired through [[trade]] or as a reward for completing [[Events#World quest incidents|world quest events]].

== Acquisition ==
{{Acquisition}}

It also appears as part of the ship featured in the [[ship to the stars]] quest.

== Summary ==
A [[ship]] requires a ship computer core to launch.

The ship computer core also has two command functions:
* '''Show launch report''': Displays launch status of the ship and a list of colonists on board.
* '''Launch ship''': Launches a fully complete ship. Any colonists not on the ship will be left behind.
