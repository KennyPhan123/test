'''Ancient display bank''' are [[ruins]] that are defined in Core but only appear when the [[Ideology DLC]], the [[Biotech DLC]] and/or the [[Odyssey DLC]] are enabled.

== Occurrence ==
If the Ideology DLC is enabled, they can be found in the [[ancient complex]] quest site.

If the Biotech DLC is enabled, they can be found in the [[mechanitor complex]] quest site.

If the Odyssey DLC is enabled, they can be found in the following locations:
* Landmarks: [[Landmarks#Ruins|ancient ruins]], [[frozen ruins]]
* Biome ruins: [[scarlands]] ruins, [[glacial plain]] ruins
* Quest sites: [[Quests#Ancient Reactor|ancient reactor]], [[Quests#Frozen Terraformer|frozen terraformer]]

If none of these DLC is enabled, they will not appear in-game at all.
