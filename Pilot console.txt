A '''pilot console''' allows colonists to control and launch a [[gravship]].

== Acquisition ==
{{Acquisition}}

== Summary ==
{{Image Wanted|section=1|reason=Gizmos, with some desc of function, also consider adding same to [[Gravship]] as appropriate}}
{{Main|Gravship}}

A pilot console is required to launch a [[gravship]]. Provided all the [[Gravship#Summary|other requirements]] are met, the gravship launch can be initiated by either selecting the console, or selecting a colonist and right clicking the console. This will start the gravship launch [[ritual]], where selected colonists will board, and animals and [[mechanoid]]s{{BiotechIcon}} will board if commanded to. After everyone is boarded and the pilot reaches the console, the launch will commence.

Only the pilot console closest to the grav engine will be functional, however, multiple pilot consoles can be built on a gravship and will not prevent a launch. If a console is destroyed, the next intact console can be used immediately.

== Analysis ==
Keeping the pilot console in a fortified location will help if an emergency evacuation is needed. If planning to travel to [[orbit]], having the [[vacuum]] protection is also helpful. Alternatively, having multiple pilot consoles in different locations will allow a launch even if one is destroyed.
