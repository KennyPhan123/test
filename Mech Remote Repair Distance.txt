== Explanation ==
This stat is only shown on mechanitors (i.e. they have an installed [[mechlink]]). Furthermore, it is only affected by the [[Remote repairer]]. The value is 0 by default and the final value is simply equal to the offset from the current level (installed count) of the ''Remote repairer''. It represents the maximum distance in cells or tiles that a pawn can use the remote repair ability on player controlled mechanoids (excluding [[War urchin]]s, which cannot be repaired). It is effectively limited to a maximum of '''{{P|Effective Maximum}}''' cells/tiles: A mechanitor with a level 3 remote repairer ({{+|19.9}}).
