== Explanation ==
[[Mech Work Speed Offset]] is applied as an offset to [[Global Work Speed]] for mechanitor controlled mechanoids. Every mechanoid except for the [[Tunneler]] (150%) has a default ''Global Work Speed'' of 50%, and some have special modifiers to certain work types. Combat mechanoids cannot perform any type of work, meaning that work speed is only relevant to the following (work) mechanoids:
* Lifter
* Constructoid
* Fabricor
* Agrihand
* Cleansweeper
* Paramedic
* Tunneler
