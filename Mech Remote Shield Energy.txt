== Explanation ==
This stat is only shown on mechanitors (i.e. they have an installed [[mechlink]]). Furthermore, it is only affected by the [[Remote shielder]]. The value is 0 by default and the final value is simply equal to the offset from the current level (installed count) of the ''Remote shielder''. It represents the energy of the [[shield]] that can be applied to any mechanoid from the remote shield ability.
