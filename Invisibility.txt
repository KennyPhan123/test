Upon cast, invisibility makes enemies unable to target the affected pawn. Pawns with 0% [[psychic sensitivity]], such as those with the [[psychically deaf]] trait, cannot be targeted by invisibility, but sensitivity does not modify the duration.

Despite the description stating that it psychically manipulates the would-be observers around the target, pawns with 0% [[psychic sensitivity]] can '''not''' see pawns that have Invisibility cast on them.

== Analysis ==
Invisibility allows mission-critical pawns to work unimpeded, making it a respectable psycast despite the high neural heat cost. 

Some noteworthy targets and purposes include:
* Psycasters. Invisibility can allow low-range psycasts like [[berserk pulse]] to be used more effectively. It can be self-cast or cast on another psycaster.
* Users of raid-ending weapons like [[doomsday rocket launcher]]s and [[orbital bombardment targeter]]s. If these weapons need to be used, failure is likely to result in complete devastation, so invisibility's protection is valuable.
* It can be cast on [[sniper rifle|snipers]] in order to aggro [[siege]]s while leaving the sniper unharmed.
* It can be cast in order to help get melee fighters in combat, ranged fighters out of combat, or to rescue downed pawns. [[Skip]] is likely a better psycast for these purposes, but Invisibility can act as a decent substitute if skip isn't available.
* It can be used to infiltrate enemy lines, destroying key targets like rocket launcher pawns and [[condition causer]]s. With high neural heat and ideally a [[kill-focused]] [[persona weapon]], a psycaster can do major work on a raid.

Note that it does not work well with the [[Defense_tactics#Melee_blocking|melee blocker]] strategy, as invisible pawns do not block hostiles from pathing through them.

Compared to [[revenant vertebrae]],{{AnomalyIcon}} the Invisibility psycast can target any pawn in sight, and be chained multiple times in a row, at the cost of neural heat. Both can be used together for a longer duration.
