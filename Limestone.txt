'''Limestone''' is a natural structure that can be [[mine]]d to obtain a {{Icon Small|Limestone block}} limestone {{Icon Small|Stone chunk}} stone chunk. Do note that this is not a guarantee.

== Summary ==
'''Limestone''' tiles have 700 health each, making it the second hardest stone block to mine. Each mined block has ~25% chance base to yield a {{Icon Small|Limestone block}} limestone {{Icon Small|Stone chunk}} stone chunk, each of which can be transform into {{Icon Small|Limestone block}} 20 limestone blocks.

This tile can also be [[Structure#Smoothed_walls|smoothed]] to create [[Smoothed limestone]].
