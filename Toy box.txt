The '''toy box''' is a [[furniture]] item added by the [[Biotech DLC]]

== Acquisition ==
{{Acquisition}}

== Summary ==
The toy box allows an adult to play with a [[baby]] using toys, as one of the play activities that get chosen at random. Compared to other activities, the toy box increases the baby's rate of [[Baby#Play|Play]] gain by 25%, as well as the adult's rate of Social [[Recreation]] gain by 25%.

Toy play is only available when a valid toy box can be found. First, the game searches for a valid toy box in the baby's room. If no toy box in the room can be reached by the adult, the game searches for the closest reachable toy box within 15.9 tiles of the adult and the baby. If no suitable toy box can be found, another play activity is chosen instead.
