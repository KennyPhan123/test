The void node is a structure{{Check Tag|?}} located in the [[metal hell]], accessed by a fully awakened [[void monolith]] as a part of the terminal of the [[Endings#Monolith endgame|monolith quest]].

== Occurance ==
{{Main|Endings#Monolith endgame}}

The void node appears in the [[metal hell]]. The metal hell, in turn, is unlocked after defeating level 3 of the [[void monolith]]. For more details, see [[Endings#The Void|Anomaly ending]].

== Summary ==
The void node can be be touched when you select it with a colonist. When doing so, the game will prompt you with two options, each leading to an Anomaly [[ending]].
* '''[[Endings#Ending - Disrupt the link|Disrupt the link]]''' returns the monolith back to an inactive state, along with [[monolith fragment]]s that can be studied. This ending grants 10 [[shard]]s, a small colony-wide [[mood]] boost, and [[goodwill]] with all factions.
* '''[[Endings#Ending - Embrace the Void|Embrace the void]]''' grants the interacting colonist the ''Void touched'' [[hediff]], granting various unique bonuses, and keeps the monolith active.

In either case, all living entities outside [[containment]] will be killed and the [[unnatural darkness]] will end.

== Analysis ==
Assuming the colony can handle every [[entity]] event, embracing the void is the ending with the better gampeplay benefit. Embracing the void offers an entirely unique boost to a single colonist, which can be duplicated via [[corrupted obelisk]], while disrupting the link only grants goodwill and resources, both of which can be obtained via other means.

When deciding to embrace the void, the colonist chosen to enter the metal hell and interact with the void node is important. [[Psycast]]ers{{RoyaltyIcon}} are often the best gameplay choice due to the [[Psychic Sensitivity]] boost, otherwise an important and valuable colonist should be given void touched. [[Creepjoiner]]s are less ideal choices as they cannot be duplicated by a corrupted obelisk.
